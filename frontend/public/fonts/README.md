# Resonance type specimens

These self-hosted fonts supply six of the seven alternating hero-title frames and the navigation. The dotted frame is custom SVG lettering. Each font is from the [Google Fonts source repository](https://github.com/google/fonts/tree/main/ofl) and is distributed under the SIL Open Font License 1.1. The copyright and license notice for each family is included beside its font file.

| Title treatment | Font file | Source and license |
| --- | --- | --- |
| Heavy condensed default | `Anton-Regular.ttf` | [Anton](https://github.com/google/fonts/tree/main/ofl/anton), `OFL-anton.txt` |
| Rounded | `Nunito-Variable.ttf` | [Nunito](https://github.com/google/fonts/tree/main/ofl/nunito), `OFL-nunito.txt` |
| Blackletter | `Astloch-Bold.ttf` | [Astloch](https://github.com/google/fonts/tree/main/ofl/astloch), `OFL-astloch.txt` |
| Industrial bold | `AzeretMono-Variable.ttf` | [Azeret Mono](https://github.com/google/fonts/tree/main/ofl/azeretmono), `OFL-azeretmono.txt` |
| Dotted | Custom SVG circles in `src/LandingPage.tsx` | Drawn for Resonance |
| Ornate script frame | `PinyonScript-Regular.ttf` | [Pinyon Script](https://github.com/google/fonts/tree/main/ofl/pinyonscript), `OFL-pinyonscript.txt` |
| Wide sans | `Archivo-Variable.ttf` | [Archivo](https://github.com/google/fonts/tree/main/ofl/archivo), `OFL-archivo.txt` |

`Roboto-Variable.ttf` is for the small uppercase navigation and labels ([source](https://github.com/google/fonts/tree/main/ofl/roboto), `OFL-roboto.txt`). The script face is a temporary animation frame, not the permanent wordmark. The default and reduced-motion title use Anton.
